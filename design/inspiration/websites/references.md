# Website Design References

These references are for visual and interaction inspiration only.

They should NOT be copied directly into the portfolio.

---

## 1. ChainGPT — Winter Edition

Reference:
https://dribbble.com/shots/23317092-ChainGPT-Website-Winter-Edition

### What I like

* Interactive 3D visual elements
* Components that feel alive rather than static
* Smooth movement between interface states
* Depth and spatial composition
* The relationship between UI and 3D
* Movement that contributes to the visual identity
* A strong hero/visual experience

### What to take from it

Use as inspiration for:

* Hero 3D interaction
* Subtle object movement
* Mouse interaction
* Spatial depth
* Transition choreography
* Interactive visual storytelling

### What NOT to copy

* Exact layout
* Branding
* Artwork
* 3D assets
* Text
* Colour system
* Exact animations

## 2. Chillo Coffee — Interactive Website

Reference:
https://dribbble.com/shots/23506056-Chillo-Coffee-Interactive-Webiste-Design

### What I like

* Strong interactive storytelling
* Components moving as part of the experience
* Product/illustration elements responding to interaction
* Smooth transitions between visual states
* The feeling that the page is an interactive composition rather than a collection of static sections
* Visual elements having a clear relationship with the brand

### What to take from it

Use as inspiration for:

* Scroll-based storytelling
* Component transitions
* Hover interactions
* Object movement
* Section-to-section continuity
* Interactive project presentation
* Motion that reinforces content

### What NOT to copy

* Exact layout
* Characters
* Illustrations
* Branding
* Artwork
* Colour system
* Exact animations

# Portfolio Motion Direction

The common principle I like from both references is:

> **The interface should feel alive, but the motion should remain intentional.**

Motion should make the portfolio feel like a product.

It should NOT feel like a website where every element is animated just to demonstrate animation.

Preferred characteristics:

* smooth
* slow
* responsive
* spatial
* subtle
* intentional
* lightweight

Use motion to communicate:

* depth
* hierarchy
* interaction
* transition
* continuity
* exploration

Avoid:

* constant movement
* excessive parallax
* aggressive cursor-following
* animations on every element
* distracting effects
* unnecessarily complex WebGL
* motion that makes content harder to read
